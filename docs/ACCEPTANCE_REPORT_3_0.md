## 阻塞和剩余风险

1. 真实外观匹配仍被 0 条确认特征阻塞；机器候选不能替代逐条植物学审核。
2. 真实脂肪酸查询仍被原 PDF 没有可靠单位/存在数值歧义阻塞；不要确认 97 条候选，除非核验原始表头/可靠外部来源。
3. 数据库中的通用植物/样本状态仍有 33/89 条 NEEDS_REVIEW；单字段油率核验与对象级核验不同。
4. GBIF 接受结果目前只确认候选状态，没有独立的本地接受学名历史字段；原课程名未覆盖，但还需补模型和修订 UI。
5. 管理审核缺完整历史对比/撤销和批量筛选；外部自动来源只有 GBIF 名称匹配候选，不含外部生物学事实和图片。
6. 本次集成测试使用当前开发数据库，不是隔离库。临时业务数据和带 E2E 标记的测试审核事件均已清理；候选导入和 31 条语义修正审计保留。后续持续开发应改用独立 MySQL 测试库。

## 运行和管理

数据库按 `README.md` 的顺序初始化 `schema.sql`、seed 和迁移，然后设置 `DB_URL`、`DB_USER`、`DB_PASSWORD`、`UPLOAD_DIR`。本机候选数据导入默认 dry-run：

```sh
./scripts/import_evidence_candidates.sh --dry-run
./scripts/import_evidence_candidates.sh --commit
./scripts/export_data_quality_report.sh
```

首次管理员仍通过环境变量 `BOOTSTRAP_ADMIN_USERNAME`、`BOOTSTRAP_ADMIN_DISPLAY_NAME`、`BOOTSTRAP_ADMIN_PASSWORD` 执行 `./scripts/bootstrap-admin.sh`。部署 Tomcat 10.1 前仍需单独配置 TLS、Session cookie、SMTP、持久图片路径和最小权限数据库账号；本项目未部署。
