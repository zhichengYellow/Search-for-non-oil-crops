- 文件：`docs/课程设计资料.pdf`
- 页数：19 个物理页；印刷页码对应物理页码 +10（11–29）。
- 文件大小：9,298,489 bytes；SHA-256：`669e9adbfbdfb855d196e5389b2b8aee763a226fee0ce7f0a7e83bc5bab73685`。
- 文本层：19 页均没有可提取文字；每页为全页扫描图像，现有核验渲染约 1233×1695 像素。
- 页面混排植物文字、植物图、油脂测量表和化学表；不能仅依靠 PDF 文本层或 OCR。

## 提取与页面关联

结构化资料中有 33 条植物记录。15 个起始页各出现两条植物条目；这些条目的 `plant_id`、起始页和顺序独立记录，没有把同页植物合并。物理第 3–10、12–14、16–19 页各有两条；第 1、2、15 页各有一条；第 11 页是延续表格页。

课程库有 33 株植物、89 条采样记录和 45 张图片裁切。45 张图片均有植物关联、来源页和裁切框。另生成 33 张表格证据裁切，登记在 `data/pdf_extract/pdf_inventory_and_crop_manifest.json`。裁切图是证据定位材料，不能单凭裁切证明物种身份。

可重复生成：

```sh
python3 -m pip install -r requirements-data-extraction.txt
python3 scripts/build_pdf_evidence_artifacts.py
python3 scripts/build_trait_evidence_candidates.py
```

OCR 和规则仅用于提出候选。页面、OCR 片段、裁切引用及物理/印刷页码保存在 `data/pdf_extract/`，OCR 置信度不等同人工核验。

## 数值和识别限制

- 扫描页无文本层，自动重建对小字号、小数点和相邻列敏感。
- 物理第 11 页（印刷第 21 页）视觉表头将含油率、碘值、酸值、皂化值和脂肪酸列并列；脂肪酸列头没有可明确确认的单位。
- OCR 曾错读含油率小数并合并表格列。因此保存 12 行逐格转录候选及 97 个脂肪酸单元格候选，没有将 OCR 数字作为正式组分值。
- 页面 11 的候选行合计出现 172.32 和 100.101 等异常；行合计仅作复核提示，不能单独决定接受/拒绝。
- 748 个不能可靠关联样本与脂肪酸列的 OCR 数字片段保持未分配，不作为化学测量导入。
- 不能可靠确认的脂肪酸单位和数值留在候选表；另有 3 条印刷学名标记待人工复核。没有把缺失值补 0。

PDF 原件未修改。全页核验图在 `data/source_pages/`，表格证据裁切在 `data/pdf_extract/table_crops/`。
