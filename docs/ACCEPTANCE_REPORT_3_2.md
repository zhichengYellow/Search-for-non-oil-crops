# PlantScope 3.2 阶段验收

验收日期：2026-10-11。范围为本次工程升级及当前本地 Docker MySQL 数据库；不是生产部署验收。

## 结果概览

**数据库扩展、来源分层、候选采集与审核、分类浏览和导入测试闭环已实现。知识库内容扩容仍未达到第一阶段建议规模。** 当前仍只有 33 株课程植物，另有 3 条待审核 GBIF 分类候选；本阶段审核通过/发布的新物种为 0。没有为了凑数创建植物空壳。

课程原始植物、样品、图片和含油率记录已在迁移前后比较行数据哈希，内容一致。迁移可在预备库上回滚，核心业务表仍保留。

## 发布和数据门槛

- 33 株旧课程记录保留既有 `is_public=1` 列表行为。它们不是经过 3.2 通用知识库发布门槛的新条目：`GENERAL_BOTANY` 已发布数为 0，身份状态 `VERIFIED` 数为 0。
- 只有审核状态 `CONFIRMED` 的特征才参与外观检索；当前 0 条。
- GBIF match confidence 只作为 API 诊断字段，不视为识别准确率或生物学核验证明。
- 没有正式脂肪酸组分；因原表单位未证实，97 个候选保持待核验。
- 缺失值保持缺失，没有转换为 0。
