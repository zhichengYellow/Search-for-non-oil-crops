## 重点检查结果

- SQL 查询使用 `PreparedStatement`；排序字段和方向来自固定白名单。油率范围与组分过滤关联到同一个 `plant_oil_samples` 及其 `sample_id`，不跨采样记录拼接。
- 含油率状态、采样记录状态和脂肪酸组分状态分别保存。高级数值范围、数值关键词和含油率排序只读取已核验测量；公开详情对未核验数值显示待核验，不显示为百分比事实。空值仍为 SQL `NULL`，不补成 0。
- 认证及管理员过滤器每次请求重新查询账户启用状态和角色；CSRF Filter 拦截缺失或无效令牌的 POST。登录后轮换 Session，退出时使 Session 失效。
- 当前数据库实际记录：33 条植物、45 张关联图片、89 条采样记录、88 条已核验含油率记录、0 条脂肪酸组分记录。该统计来自 MySQL 查询；课程 PDF 的质量和 OCR 限制见 [DATA_QUALITY.md](DATA_QUALITY.md)。
- 图片上传端到端测试使用临时生成 PNG 样本，不代表对 45 张课程资料裁切图逐一重新目视审核。

## 剩余风险

- Tomcat/反向代理生产配置需启用 HTTPS 与 `SESSION_COOKIE_SECURE=true`，并配置适合部署环境的 SameSite Cookie 策略。
- `Database` 当前通过 `DriverManager` 为请求建立 JDBC 连接，没有连接池；适合课程规模，较高并发下需替换为容器数据源或连接池。
- 登录没有账户锁定或速率限制；正式公开部署前应增加防暴力尝试措施、日志监控和 TLS 终止配置。
- 图片服务校验大小、扩展名随机化及文件签名，但没有执行完整图像解码/重编码；正式接收不可信上传时建议增加解码重编码和恶意文件扫描。

## 启动与交付

先启动并初始化 MySQL，配置 `DB_URL`、`DB_USER`、`DB_PASSWORD`、`UPLOAD_DIR`，然后构建并部署：

```sh
mvn clean package
cp target/oil-plants-knowledge.war "$CATALINA_BASE/webapps/"
"$CATALINA_BASE/bin/catalina.sh" run
```

首个管理员通过 `BOOTSTRAP_ADMIN_USERNAME`、`BOOTSTRAP_ADMIN_DISPLAY_NAME`、`BOOTSTRAP_ADMIN_PASSWORD` 环境变量执行 `./scripts/bootstrap-admin.sh`。脚本拒绝覆盖已存在用户名；不会预置默认密码。

可交付 WAR：`target/oil-plants-knowledge.war`。本报告不表示已经执行独立服务器部署。
