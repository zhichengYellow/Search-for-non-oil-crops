## 重点检查结果

- 数据统计来自当前配置的 MySQL：33 条植物、45 张关联图片、89 条采样记录、88 条已核验含油率、0 条已核验脂肪酸、0 条已确认外观特征。测试结束后随机账户、植物、验证码和浏览统计无残留。
- 含油率、样本状态、脂肪酸组分状态分开保存。数值筛选遵守核验状态并限定同一个 `sample_id`；缺失仍为 `NULL`，不补成 0。
- 外观检索只对已确认且有来源的事实评分；待核验、未知和争议事实不视为冲突。匹配分数是启发式排序，不是识别概率。由于当前确认特征数为 0，系统对真实课程条目应显示证据不足。
- 描述搜索采用有限中文词典/规则，不调用付费 AI API；识别的条件可修改。搜索建议、植物对比、检索历史、最近浏览、热门统计均由 MySQL 数据驱动。
- 植物对比固定展示 2–3 个数据库植物，含油率/组分始终按各自样本列出。每日热门统计不保存 IP，按 30 日计算并清理 90 日前数据。
- 所有新增迁移均为增量迁移；没有重写 `docs/课程设计资料.pdf` 或为课程植物添加无来源的特征事实。

## 未完成或未验证

- 0 条已确认外观特征；真实课程植物无法形成有证据的外观候选。管理员需要根据原始 PDF 或可靠外部来源逐项录入并审核。
- 没有自动连接 GBIF/POWO/WFO 的导入适配器；外部来源的事实没有自动写入或覆盖课程资料。
- 用户观察记录未实现；图像辅助识别和 AI 语义检索只是可选后续方向。
- SMTP 配置通过开发邮箱收件箱端到端验证；真实邮件提供商、DNS/TLS 投递未验证。
- 图形验证码签发频率目前按 Session 限制；多节点生产部署还需要共享限流或边缘层限流。
- 未部署到独立 Tomcat、云或生产；未做并发、渗透、备份恢复测试。管理员后台及全部登录注册表单未逐视口浏览器回归。
- 尚无可核验脂肪酸百分比数据，因此没有可用于验证的非空组分图表。

## 启动和交付

新数据库按 `README.md` 的顺序执行 `schema.sql`、`seed.sql` 和 `database/migrations/` 迁移，再配置 DB、SMTP/邮件密钥与图片目录。首次管理员使用 `BOOTSTRAP_ADMIN_USERNAME`、`BOOTSTRAP_ADMIN_DISPLAY_NAME`、`BOOTSTRAP_ADMIN_PASSWORD` 执行 `./scripts/bootstrap-admin.sh`。

独立 Tomcat 启动示例：

```sh
mvn clean package
cp target/oil-plants-knowledge.war "$CATALINA_BASE/webapps/"
"$CATALINA_BASE/bin/catalina.sh" run
```

可交付 WAR：`target/oil-plants-knowledge.war`。该文件已在嵌入式 Tomcat 中验证，**没有部署到独立服务器**。
