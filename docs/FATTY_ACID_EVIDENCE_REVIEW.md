## 建议人工审核顺序

1. 先核实论文可合法使用的许可与来源记录；现在未确认，不能把“本地可读”理解为“可再分发”。
2. 对每个研究样本分别核对拉丁学名、种/变种层级、中文名、表 1 或表 2 样本号、产地/采集日期和样本部位。不要把 2014/2018 研究样本关联到课程 PDF 中看似相同的旧样本。
3. 对每个候选值按证据图逐格核验表头、行号、组分列和数字。PDF 文本层可帮助定位，但不能替代原页视觉核对。
4. 独立确认含油率的物料基础与单位，不把含油率当脂肪酸组成；独立确认各文献脂肪酸百分比的分析对象和测定口径，不跨论文直接比较。
5. 破折号、空白和无法判读的格继续作为缺失/未知；只有原表明确印出的 `0.00` 才是数字零。破折号格不在数值候选 CSV 中形成一条伪造的 0 候选。
6. 记录实际审核者、时间、备注和依据；若发现身份、表头、数值或许可有争议，退回或维持待审。不能补填虚构的管理员账号。

现有审核服务会阻止在来源状态未确认、原来源不一致或组分单位不明确时确认候选。该限制需要保留；不能为了“至少有一条正式组分”绕过。三批导入使用既有 `plant_oil_samples` / `fatty_acid_candidates` 关系，没有新增表。当前本地用户表为 0 个用户，故本轮没有可记录的真实具名审核者。

## 数据完整性与当前边界

- 提取记录：172 个论文样本行；精确关联 27 个，未关联 145 个。
- 数值组分候选：198；原表破折号单元格 130 个；被排除的紫苏 UFA 汇总值 10 个。
- 正式组分：0；含油率已核验样本仍为 88；全库论文样本 27 条均未提升为已核验值。
- USDA Foundation Foods 不属于这些油料植物实验。其食品脂肪酸以 g/100 g 食品为计量基础，本轮不换算为油中百分比，不写入专业植物油查询。许可及计量定义来源见 [USDA Foundation Foods 文档](https://fdc.nal.usda.gov/Foundation_Foods_Documentation/) 与 [FoodData Central](https://fdc.nal.usda.gov/)。

正式数据库汇总前后增加 27 个独立论文样本、3 个 `NEEDS_REVIEW` 文献来源、198 个待审核组分候选和相应创建审核事件；另有 3 条来源官网 URL 核验/修正事件。课程植物、已有 89 个样本、88 个已核验含油率、原 97 个组分候选及过往审核事件均保留。最终审核事件共 2,791 条。当前实际计数及备份信息见 [`FATTY_ACID_IMPORT_REPORT.md`](FATTY_ACID_IMPORT_REPORT.md)。
